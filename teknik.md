Padahal kebutuhan developer remote jauh lebih sempit.

# Prioritas 1: Reading (40%)

Sebagai backend developer, 70% pekerjaan adalah membaca.

Yang dibaca:

* Dokumentasi
* Issue GitHub
* Pull Request
* Error message
* API docs
* Chat Slack

Mulai setiap hari:

### 15 menit

Baca:

* [Node.js Documentation](https://nodejs.org?utm_source=chatgpt.com)
* [TypeScript Documentation](https://www.typescriptlang.org?utm_source=chatgpt.com)
* [MDN Web Docs](https://developer.mozilla.org?utm_source=chatgpt.com)

Jangan diterjemahkan kata per kata.

Pahami konteks.

Contoh:

```text
The middleware executes before the request reaches the route handler.
```

Langsung pahami:

> Middleware dijalankan sebelum request sampai ke handler.

Total:

```text

Dalam 1 tahun:

Untuk kondisi Anda (semester 11, backend developer, ingin kerja remote), saya akan lebih menyarankan:

**70% waktu meningkatkan backend engineering (Node.js, TypeScript, System Design, Docker, PostgreSQL, AWS) dan 30% waktu untuk English.**

Perusahaan luar negeri biasanya lebih mudah memaafkan English yang belum sempurna daripada skill engineering yang lemah. Namun mereka jarang memaafkan skill engineering yang lemah meskipun English sangat lancar.



Ya, **dalam beberapa bulan Anda bisa mencapai level yang cukup untuk interview dan kerja remote**, tetapi targetnya harus realistis.

Jika saat ini Anda:

* Sudah bisa membaca sedikit bahasa Inggris teknis.
* Sudah paham backend development (Node.js, TypeScript, Express, MongoDB/PostgreSQL).
* Hanya kesulitan komunikasi bahasa Inggris.

Maka **3–6 bulan belajar yang terarah** bisa memberikan perubahan besar.

## Target yang Tepat

Jangan menargetkan:

> "Saya harus lancar seperti native speaker."

Targetkan:

> "Saya bisa menjelaskan pekerjaan saya, memahami instruksi kerja, dan mengikuti interview."

Banyak developer remote dari India, Vietnam, Brasil, Turki, dan Indonesia bekerja dengan English yang tidak sempurna.

Belajar hanya hal yang sering muncul dalam pekerjaan.

Daripada menghafal rumus grammar:

```

Lebih berguna menghafal:

```text

I have fixed the bug.

I am investigating the issue.

The deployment was successful.

The API is working as expected.
```

# Trik yang Jarang Diketahui

Ubah semua lingkungan kerja menjadi bahasa Inggris:

* IDE
* Browser
* GitHub
* Dokumentasi
* ChatGPT
* Error messages

Dan mulai berpikir dengan kalimat sederhana:

```text
I need to fix this bug.

I need to create a new endpoint.

This query is slow.

The API returns an error.
```

Semakin sering otak terpapar bahasa Inggris dalam konteks kerja, semakin cepat kemampuan Anda berkembang.

Dengan latar belakang Anda yang sudah belajar backend dan sering berinteraksi dengan dokumentasi teknis, target yang realistis adalah:

* **2–3 bulan:** mulai nyaman membaca dokumentasi dan chatting kerja.
* **4–6 bulan:** mampu mengikuti technical interview junior–mid level dengan persiapan yang konsisten.
* **6–12 bulan:** cukup kompetitif untuk banyak posisi remote internasional jika skill teknis juga kuat.
